Zero to professional — 7 steps

0 · The situation. Your app resends the whole history each turn; the server reprocesses it (prefill) before answering.
1 · Why it hurts. Long context → long prefill → slow first word (TTFT) and big bills.
2 · The trick. Each word stores a key+value; new words only score old keys. Old rows never change → keep them. Error vs recompute: 1.15e-14.
3 · Across requests. Next turn starts with this turn's exact tokens → reuse the matching prefix. Paraphrases miss: 3/3 vs 1/3 blocks.
4 · The catch. Memory: 320 KiB/token at 70B (10 GiB/32K). Small cache: 0% reuse. Bigger: 67%.
5 · The pro question. How much cache for your target? Read the working set off the curve: 122 @70%, 136 @80%. Name the target first.
6 · Reality. Live data is heavy-tailed (p99 ≈ 6× p50). Locality beats memory (0.846→0.388). Normalize block sizes by tokens, never block count.

FAQ (short)

Do I need a GPU?No. NumPy-only; seconds on a laptop.
Why did my reworded prompt miss?Block keys embed every prior token — one changed word re-keys its block and all after it. Keep system prompts byte-stable.
What capacity do I provision?Measure your trace, pick a target (e.g. 80%), read the working set, add drift headroom, re-measure continuously.
Is the KV cache "knowledge"?No — temporary attention state. Evict it and answers are identical, just slower.
Offline machine?Everything works except the live fetch (EXP-05 flags a deterministic fallback instead of failing).

Glossary (12 terms)

Prefill / Decode. Whole-prompt processing → first token; then one token at a time.
TTFT / TPOT. Time to first token / per output token. Prefix hits cut TTFT.
Token. Numbered word-piece; caches match tokens, not meanings.
K / V / Q. Key, value, query projections; queries score keys, blend values.
Prefix cache. Cross-request K/V reuse of a shared leading span.
Block. Fixed token group (e.g. 16) — the cache/eviction unit.
Hit rate. Share of needed blocks served from cache.
LRU. Evict least-recently-used first.
Stack distance. Distinct pages since last use; hit iff ≤ capacity.
Working set. Smallest capacity hitting your target rate.
Knee. Point where more memory buys ~nothing.
Cache salt. Per-tenant hash salt isolating prefixes (security).
